# db-booking_flights-
Создание базы данных для системы бронирования авиабилетов

## Сайт на Django

В папке [`web/`](web/) — интерактивный сайт на Django на основе этой базы: поиск рейсов, бронирование с выбором места, просмотр и отмена броней, админ-панель. Инструкция по запуску — в [`web/README.md`](web/README.md).
