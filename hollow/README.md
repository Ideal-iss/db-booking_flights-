# THE HOLLOW

Браузерная RPG от первого лица в духе VHS/PS1: тёмное фэнтези, процедурные подземелья, кооператив.
Играется по адресу `/world/` сайта SkyBook (Django-приложение `web/hollow`).

## Что внутри

| Папка | Что это |
|---|---|
| `shared/` | Общий код клиента и сервера: данные (классы, навыки, предметы, враги, подземелья), генератор подземелий по сиду, физика Rapier, **симуляция боя** (`shared/sim`). |
| `client/` | Игра: Vite + React + TypeScript + Tailwind + Zustand + Three.js. Рендер в низком разрешении с VHS/PS1-шейдером, процедурные текстуры, модели, звук на WebAudio. |
| `server/` | Сервер кооператива на Colyseus: авторитетно крутит ту же симуляцию для отряда. |
| `../web/hollow/` | Django: аккаунты, персонажи, инвентарь, торговец, кузнец, забеги, проверка добычи, приём отчётов кооператива. Сборка клиента лежит в `web/hollow/static/hollow/`. |

## Как устроена игра

* **Одиночная игра.** Сервер выдаёт сид забега, клиент генерирует подземелье и крутит симуляцию сам. Предметы сохраняются на сервере сразу при подборе; сервер проверяет, что предмет мог выпасть (база, редкость, диапазоны свойств, уровень). Опыт и золото начисляются в конце забега с верхними пределами. Честно: полностью защититься от подделки в одиночной игре нельзя, потому что симуляция идёт в браузере.
* **Кооператив.** Django выдаёт подписанный HMAC пропуск со снимком персонажа. Сервер Colyseus проверяет пропуск, создаёт отряд с кодом `HOLLOW-1234`, после готовности всех запускает симуляцию у себя (20 тиков/с), принимает от клиентов только позу и действия, проверяет скорость перемещения и проходимость клеток, ограничивает частоту сообщений. Добычу и итоги он отправляет в Django подписанными запросами. Отряд — 2 игрока (`PARTY_SIZE`, код рассчитан до 4). При обрыве связи есть 60 секунд на возврат.

## Разработка

```bash
cd hollow
npm install
npm run dev            # клиент на :5173, API проксируется на Django :8000
npm run typecheck
npm run sim:test       # прогон симуляции: все подземелья × все классы, сундуки, тайники, боссы
npm run export-data    # выгрузить таблицы игры в web/hollow/gamedata.json для Django
npm run build          # собрать клиент в web/hollow/static/hollow/
npm run server:dev     # сервер кооператива на :2567
```

Django: `cd web && python manage.py migrate && python manage.py runserver`, тесты — `python manage.py test hollow booking`.

## Включить кооператив

1. Задеплоить сервер: Render → New → Blueprint → этот репозиторий (файл `render.yaml` в корне). В переменной `HOLLOW_SECRET` указать длинную случайную строку.
2. В `.env` Django (на PythonAnywhere — `~/db-booking_flights-/web/.env`) добавить:
   ```
   HOLLOW_COOP_URL=wss://<имя-сервиса>.onrender.com
   HOLLOW_COOP_SECRET=<та же строка>
   ```
3. Перезагрузить сайт. У Алтаря Клятвы в лагере появятся «Создать отряд» и «Войти по коду».

Бесплатный сервер Render засыпает через 15 минут без игроков и просыпается примерно за минуту при первом подключении.

## Управление

WASD — ходьба, мышь — обзор, Shift — бег, Пробел — уклонение, ЛКМ — атака (зажать — сильная; лук — натяжение), ПКМ — блок/парирование, магический заслон или прицел, Q/R/F — навыки, 1/2 — зелья, E — действие, I — сумка, C — персонаж, B — навыки, M — карта, Esc — пауза.
